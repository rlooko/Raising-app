# 🏘️ 용은타운 (권용은 키우기)

하루 10분 타임어택으로 **나를 레벨업하는 작은 인생 게임**입니다. 이제 홈은 **Three.js 3D 파스텔 마을 「용은타운」** 이에요.
아이폰 홈 화면에 추가하면 앱처럼 전체 화면으로 열립니다.

**배포 주소:** <https://rlooko.github.io/Raising-app/>

- **파일**: `index.html` 하나 (3D 마을만 Three.js를 CDN에서 불러오고, 그 외 기능은 외부 의존성 0)
- **오프라인**: 인터넷이 없거나 CDN·WebGL을 못 쓰면 자동으로 **2D SVG 마을**로 돌아갑니다 (모든 기능 그대로)
- **아이콘**: `icon-180.png` (홈 화면 아이콘, HTML 안에도 내장되어 있음)
- **저장**: 이 기기 브라우저의 `localStorage`에만 저장. 서버로 아무것도 보내지 않습니다.

## 1. 아이폰에서 여는 방법

### 방법 A · 그냥 열기 (가장 빠름)
1. `index.html`을 아이폰 **파일** 앱(iCloud 드라이브 등)에 넣습니다.
2. 파일을 길게 눌러 **공유 → Safari로 열기**(또는 크롬)를 선택합니다.

> 파일로 열면 그 자체로 다 동작합니다. 다만 `file://` 주소에서는 홈 화면 추가·오프라인 캐시가 제한될 수 있어요.

### 방법 B · 홈 화면에 앱처럼 추가 (추천)
1. 아래 **방법 C**로 웹 주소를 하나 만듭니다.
2. Safari에서 그 주소를 엽니다.
3. 하단 **공유 버튼 → 홈 화면에 추가** → 이름은 `권용은 키우기`.
4. 홈 화면 아이콘을 누르면 주소창 없는 전체 화면 앱으로 열립니다.

### 방법 C · 무료 호스팅 1분 배포
`index.html`과 `icon-180.png` **두 파일을 한 폴더에** 두고, 아래 중 하나를 쓰면 됩니다.

| 서비스 | 방법 | 비고 |
|---|---|---|
| **Netlify Drop** | <https://app.netlify.com/drop> 에 폴더를 끌어다 놓기 | 가장 간단, 무료 계정 필요할 수 있음 |
| **Cloudflare Pages** | 대시보드 → Pages → “Upload assets” 로 폴더 업로드 | 무료, HTTPS 주소 발급 |
| **GitHub Pages** | 저장소에 두 파일을 올리고 Settings → Pages 활성화 | 깃허브 계정이 있으면 익숙함 |

배포하면 `https://...../index.html` 주소가 생깁니다. 이 주소를 Safari로 열고 홈 화면에 추가하세요.
(주소 끝의 `index.html`은 생략해도 됩니다.)

## 2. 애플워치 단축어 연동

손목에서 탭 한 번으로 20분 타임어택을 시작하는 방법입니다. **A안이 가장 확실합니다.**

### A안 · 워치에서 타이머 돌리기 (추천)
1. 아이폰 **단축어** 앱 → 단축어 탭 → 오른쪽 위 **+**
2. **동작 추가** → “타이머” 검색 → **타이머 시작** 선택 → 시간을 **20분**
3. (선택) **알림 표시** 또는 **진동** 동작을 붙이면 끝날 때 손목이 울립니다
4. 이름을 `타임어택 20분`으로 저장
5. 애플워치 **단축어** 앱에서 같은 단축어 확인 → 워치 페이스 편집 → **컴플리케이션**에 단축어 추가
6. 끝나면 앱에서 퀘스트 **완료**를 눌러 EXP 받기 (워치는 타이머, 앱은 기록 담당)

### B안 · 이 웹앱 타이머를 워치에서 열기
단축어에 **URL 열기** 동작을 넣고 아래처럼 주소를 지정합니다.

```
https://내-앱-주소/?start=20
```

- `?start=20` : 20분으로 맞춰 **자동 시작**
- `?start=20&auto=0` : 시간만 맞추고 시작은 직접
- `?tab=money` `?tab=skill` `?tab=report` : 해당 탭으로 바로 열기

> 워치에서 URL 열기는 아이폰으로 넘어가는 경우가 많습니다. 워치 단독 실행은 A안이 안정적이에요.

> 아이폰 사파리는 웹앱에서 **진동 API를 지원하지 않습니다.** 이 앱은 소리·화면 효과로 알려주고, 워치 타이머는 손목 진동으로 알려줍니다.

## 3. 무엇이 들어 있나

### 홈 — 용은타운 (Three.js 3D 파스텔 마을)
- **진짜 3D 아이소메트릭 마을**: 떠 있는 잔디 섬, 파스텔 타일 산책로, 연못·분수, 나무·가로등·벤치, 둥근 구름
- **손가락으로 드래그해 돌리고, 핀치로 확대/축소** (땅 밑으로 파고들지 않게 각도 제한). 우측 상단 **⟲ 시점 리셋**
- **파스텔 타일 길**을 **용은 + 춘배(ㅊ)** 가 아장아장 걸어 다니고, 머리 위 말풍선이 3D 좌표를 따라 움직입니다
- **5개 건물**을 직접 탭하거나(레이캐스터) 이름 칩을 눌러 바로 그 기능으로 들어갑니다

| 건물 | 탭하면 | 연결 |
|---|---|---|
| 🏰 데이터 성 | 관문 진행률 · 바로 SQL 퀴즈 | 커리어 트랙 / 데이터 분석가 |
| 🏦 청산 은행 | **차용증 5,000만 원 상환 게이지** · 상환 기록 | 돈 기록 / 순현금 |
| ☕ 아렐로 작업실 | 이번 달 부업 수익 · 25분 작업 시작 | 블로그·부업·체험단 퀘스트 |
| ⏰ 타임어택 시계탑 | 10분 / 25분 시작 (돌리는 동안 **탑에 불이 켜짐**) | 타임어택 |
| 🏡 수은집 하우스 | **이사(2027-01-16)·결혼(2027-02-27) 체크리스트** | 체크할수록 집 주변에 꽃·나무·조명이 늘어남 |

- **활동을 시작하면** 캐릭터가 해당 건물 앞으로 걸어가 작업 모션 + 말풍선(`"SQL 푸는 중..."`, `"타임어택 중!"`, `"동전 넣는 중!"`)
- 상단 **LIVE 바**나 캐릭터를 누르면 **미니 상태 카드** (현재 작업·진행률·XP·오늘 성과 4칸)
- **낮 / 노을 / 밤** 자동 전환(06–17 낮, 17–20 노을, 20–06 밤) + 우측 상단 아이콘으로 수동 미리보기(자동→낮→노을→밤)
  - 3D에서도 실제로 바뀝니다: 태양·달빛 색온도와 방향, 하늘색, **건물 창문 발광(emissive)**, **가로등 불빛**, 별
  - 타임어택을 돌리는 동안에는 **시계탑 꼭대기 등불이 켜지고 시계 바늘이 남은 시간을 가리킵니다**
- **실행 로그**: 완료한 퀘스트·기록이 시각과 `✓ DONE` / `₩ 기록` 배지로 쌓이는 접이식 패널
- 레벨·칭호·EXP 바·연속 기록(스트릭), 오늘 얻은 EXP
- 레벨에 따라 **6단계로 진화** (새싹 → 스카프 → 왕관), 표정·통통 튀는 애니메이션
- 오늘의 퀘스트는 **매일 자동으로 갱신** — 어제 끝낸 퀘스트는 다음 날 다시 미완료로 뜨지 않고, 남은 퀘스트가 3개보다 적으면 그날의 추천 3개(**SQL 퀴즈 3문제 풀기 / 오늘 영어 읽기 1건 + 1줄 영작 / Outlier·부업 10분 타임어택**)가 자동으로 채워집니다. 직접 추가해 아직 안 끝낸 퀘스트는 그대로 유지 + 추가·수정·삭제·미루기

### 타임어택
- 10 / 20 / 25분 + 커스텀, 원형 진행 링, 일시정지·재시작
- 끝나면 **효과음(Web Audio) + 진동 + EXP + 축하 이펙트**
- 퀘스트·자격증을 연결하면 완료 시 자동 반영
- 앱을 닫았다 다시 열어도 남은 시간이 이어집니다
- 오늘 완료 횟수 / 이번 주 집중 시간 / 연속 기록

### 돈 — 가계부 + 안전망
- 수입 / 부업(애드포스트·Outlier·체험단) / 지출 / 고정비 기록, 월별 이동·요약·순현금
  - 부업 입력 칸에는 **애드포스트 48,558원 = 11/19 전환 신청 완료, 12/12 입금 예정** 안내가 뜹니다. 실제로 들어온 날 기록하면 됩니다.
- **안전망 게이지**: 목표액(기본 300만 원)과 현재 비상금을 비교
- 고정비·구독 목록과 매달 점검 체크
- 기록하면 소소한 EXP (하루 3건까지)

### 커리어 — 로드맵 & 관문 테스트
- **데이터 분석가**: SQLD → 통계·ADsP → Python → 포트폴리오 2건 → 이력서·면접 (단계별 미니 퀴즈 3문제)
- **9급 공무원**: 시험 구조 → 직렬·기본서 → 기출 → 모의고사 → 원서 (퀴즈 + 체크리스트)
- **병행 비교**: 두 트랙을 동시에 켜려 하면 가용 시간과 필요 시간을 계산해 경고하고, 교집합 루트(통계직·전산직) / 선택 집중을 제안
- **커스텀 로드맵**: 원하는 직업과 5단계를 직접 만들기
- 관문을 통과해야 다음 단계 해금, 통과 시 +120 EXP, 트랙 완주 시 +300 EXP와 배지
- 자격증·스킬 트리: 시험일 D-Day, 공부 시간·진도율, +10분/+25분 적립, 완료 배지

### 리포트 — 객관화 코치
- 실행 / 돈 / 커리어 3축 점수
- 이번 주 완료 수, 타임어택 횟수·시간, 미룬 횟수, 경로 이탈 경고, 연속 기록, 안전망
- 기록에 근거한 진단 코멘트 6줄
- **“내 상태 복사하기”** → 요약 텍스트를 복사해 대화방에 붙여넣으면 춘배가 이어서 피드백

### Focus Guard
- 열린 퀘스트가 3개 이상인데 새 퀘스트·스킬을 추가하려 하면 **경로 이탈 경고**
- 진행 중인 트랙이 있는데 다른 트랙을 열려 하면 **시간 비교 경고**
- 홈 상단 배너로도 알려주고, 경고 횟수는 리포트에 쌓입니다

### 설정
- 이름, 안전망 목표·시작 비상금, 하루 가용 시간
- 효과음·진동 on/off
- **JSON 백업 내보내기 / 불러오기**, 전체 초기화

- **2026-11-20 오늘의 퀘스트 갱신 수정**: 어제 끝낸 `애드포스트 48,558원 전환` 퀘스트가 다시 뜨지 않고(기본값·기존 `localStorage` 모두에서 제거), 날짜가 바뀌면 지난날 퀘스트는 정리되고 오늘 추천 3개가 자동으로 채워지는 것을 확인
  - 390×844 모바일 뷰포트·한국 시간대에서 기존 `localStorage`(q_ads 포함) 로드 → q_ads 제거·새 추천 3개 표시·새로고침 후 유지, 콘솔/페이지 에러 0건
  - 가짜 시계로 자정을 넘겨(`23:50 → 00:02`) 30초 감지 루프가 자동 갱신하는 것까지 확인
  - 돈 탭 '애드포스트 48,558원 채우기' 버튼은 12/12 입금 예정 안내로 교체, 리포트 코멘트도 정리
- 차용증 상환 1,500,000원 → 게이지 3%, 수은집 5/12 체크 → 장식 5개 표시, 새로고침 후에도 유지

## 6. 참고

- 레벨 곡선: Lv.n → n+1에 `40 + (n-1)×12` EXP
- 캐릭터 단계: Lv.1–2 → 3–5 → 6–9 → 10–14 → 15–19 → 20+
- 퀘스트 보상: 10분 +60, 20분 +70, 25분 +80 (새로 만들면 `30 + 분×2`)
- 타임어택 보상: `분×2.5 + 10` EXP, 관문 +120, 트랙 완주 +300
