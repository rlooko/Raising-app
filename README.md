# 🏘️ 용은타운 (권용은 키우기) V4

**밤 10시, 10분만 켜는 데일리 RPG.** 하루에 카드 하나만 — 오늘의 **10분 원픽** — 을 끝내면 마을이 자라고, 빚 5,000만 원 벽돌이 한 칸씩 깨집니다.

**배포 주소:** <https://rlooko.github.io/Raising-app/>

```
index.html                 화면 마크업(3탭) + 마을 SVG
manifest.json              PWA 매니페스트 · icon-180.png
css/style.css              V1~V3 기본 스타일(카드·버튼·시트·마을)
css/v4.css                 V4 레이아웃(원픽·참은 소비·랩·대시보드)
js/core.js                 유틸·소리·토스트·시트·EXP·행동 로그·CSV/백업
js/data.js                 저장 스키마(yongeun-raising-v1)·레벨·퀘스트·돈/빚 계산·원픽 규칙
js/town.js                 2.5D 마을·캐릭터 산책·말풍선·실행 로그·건물 이동
js/roadmap.js              데이터 분석가 5단계 코스·모의 테스트·면접 카드(V3 콘텐츠)
js/sql-lab.js              SQLite(WASM) 랩·미션 채점·JS SQL 폴백·GitHub 잔디
js/sync.js                 ☁️ Firebase Firestore 동기화(town_state/yongeun_main)
js/app.js                  3탭 렌더·원픽 타이머·참은 소비·가계부·대시보드·부팅
js/town3d.js               Three.js 3D 마을(+진행도 장식·날씨) — 실패 시 2D 마을
claude_bridge.py           (V3 과외용 · V4 앱은 더 이상 쓰지 않음 · 보관)
```

- **오프라인**: CDN·WebGL이 없으면 자동으로 **2D SVG 마을**로, SQLite를 못 불러오면 **가벼운 JS SELECT 폴백**으로 내려갑니다. 기록은 그대로 동작합니다.
- **저장**: 이 기기 `localStorage`(`yongeun-raising-v1`) → 인터넷이 되면 내 Firebase(**yongeun-town** `town_state/yongeun_main`)에 ☁️ 자동 백업.

## 1. 3개 탭

### 🏠 오늘 — 카드 하나만
- **오늘의 10분 원픽**: 시간대에 맞춰 자동으로 고릅니다.
  - **21:00~02:00 골든타임** → SQL 1문제 / GitHub 1커밋
  - 아침(02~11시) → 영어 원문 1문단 / 참을 소비 1건 정하기
  - 낮(11~17시) → 부업·체험단 10분 / 참은 소비 1건
  - 저녁(17~21시) → 참은 소비 1건 / GitHub 1커밋
  - **10분 집중 타이머 내장** — 끝나면 자동 완료, +40 EXP, 콤보 +1. `다른 원픽` 버튼으로 후보를 바꿀 수 있어요.
- **참은 소비 → 빚 벽돌**: `배달·커피·쇼핑·택시·간식·구독·직접` 칩을 **한 번 누르면** 기록 + 빚 벽돌 + EXP가 동시에.
  - 남은 빚 게이지 = **5,000만 원**에서 (누적 참은 소비 + 실제 상환)을 뺀 값
  - 이번 달 방어 금액 / 이번 달 목표(기본 200,000원) 게이지 / 이번 달 순현금
- **오늘 요약 4칸**: 오늘 방어 · 참은 소비 건수 · SQL 오늘 통과 · 오늘 잔디
- 접힌 것(기본 닫힘): 오늘의 퀘스트 · 가계부(안전망 포함) · 배지 · 설정/백업

### 🧪 실전 랩 — 폰에서 진짜 SQL
- **SQLite WASM(sql.js)** 을 CDN에서 불러와 브라우저 안에서 진짜 SQL을 돌립니다. **맥북·터미널 불필요**.
  - 데이터: BapZip 스타일 `p_shops`(60) · `p_orders`(870+) · `p_reviews`(660+) · `p_events`(2,300+) + 11trillion 스타일 `p_users`(500) · `p_bettings`(900)
  - **미션 5개**: ① 가을 프로모 가입자의 6단계 퍼널 ② 별점 수정 배포 검증(p_shops.rating vs 리뷰 평균) ③ 가입 주차 D7 리텐션 ④ 베팅 순손익 상위 5명 ⑤ 게임별 환수율(RTP)
  - 정답을 JS로 계산해 **즉시 채점**(컬럼 수·행 수·값 비교, 반올림 2자리). 힌트·모범 답안·시작 쿼리 버튼.
  - CDN이 막히면 **JS 폴백**(단일 테이블 SELECT/GROUP BY/ORDER BY/LIMIT)으로 내려가고, JOIN·CTE가 필요한 쿼리는 “온라인에서만” 안내합니다.
- **GitHub 잔디(@rlooko)**: `api.github.com/users/rlooko/events/public`으로 오늘 커밋·연속 일수·최근 푸시를 읽고, 10분 캐시 → 레이트리밋·오프라인이면 캐시 표시 → 캐시도 없으면 “아직 확인 전”으로 조용히 안내.
- **🎓 커리어 코스**(접힘): V3의 데이터 분석가 5단계 코스·모의 SQL/케이스 테스트·면접 카드 8선을 그대로. 면접 카드 #6은 **“크리에이터 대행 운영 경험이 데이터 분석가에게 어떤 강점이 되나요?”** 로 정리했습니다.

### 🏰 타운 & 로그 — 마을이 자라고, 데이터가 쌓입니다
- Three.js 캔디 마을: 춘배 고양이·와플 성·클릭 이동·낮/노을/밤. 화면을 못 쓰면 2D SVG 마을.
- **진행도 장식 12개**: 연속·참은 소비·SQL·EXP 점수로 꽃·가로등·깃발·나비·분수·풍선·벤치·별가루·하트 조명·무지개·축제가 하나씩 열립니다.
- **날씨**: 활동 중이면 ✨반짝 / 보통 🌤맑음 / **3일 이상 쉬면 🌧비**(비 입자·구름). `날씨` 버튼으로 미리보기 순환.
- **내 데이터 대시보드**: 최근 7일 활동 막대 · 주별 방어 금액 · SQL 통과 현황 + 한 줄 진단. `행동 로그 CSV` / `JSON 백업` 버튼.
- **실행 로그**(접힘): 미션·참은 소비·건물 체크 기록.

## 3. 기록·백업·동기화

- 저장 키는 V1~V3와 같은 **`yongeun-raising-v1`** 하나. `exp·streak·quests·money·brick·debt·house·v3Career·analyticsLogs·claude` 등 **기존 필드를 그대로 읽고**, V4 필드(`pick·pickDone·sql·gh`)만 새로 더합니다. 예전 JSON 백업도 그대로 불러와집니다.
- Firestore 경로·프로젝트도 그대로: **`yongeun-town` → `town_state/yongeun_main`** (Google API 키는 `https://rlooko.github.io/*` 리퍼러 제한).
- **기록 보호 장치(V4 추가)**: 새 폰·시크릿 창처럼 기록이 거의 없는 기기가 열려도, 기록이 있는 클라우드 사본을 덮어쓰지 않습니다. 반대로 클라우드가 비어 있으면 이 기기 기록을 다시 올립니다.
- Safari에서 “방문 기록 및 웹사이트 데이터 지우기”를 하면 사라질 수 있으니 가끔 **오늘 → 설정 · 백업 → 백업 내보내기**로 JSON을 저장해 두세요. (백업 파일에는 이름·금액이 들어 있으니 공유 금지)

## 4. EXP 규칙

| 하는 일 | EXP |
|---|---|
| 원픽 10분 타이머 완료 | +40 |
| 원픽 “이미 했어요” | +15 |
| 참은 소비 | `8 + 금액/1,000` (최대 +30) |
| 퀘스트 완료 | 30 + 분×2 |
| SQL 미션 첫 통과 | 미션별 50~70 |
| V3 코스 체크 | 주제 +12 · 스텝 +10 · 모의 테스트 +40 · 면접 카드 +6 |
| 수은집 체크 | +12 |

레벨 곡선: Lv.n → n+1에 `40 + (n-1)×12` EXP.

## 6. 참고

- `claude_bridge.py`·`.claudeignore`는 V3 과외(맥북 Claude Code 채점) 때 쓰던 도구입니다. V4는 **브라우저 SQLite 랩**으로 대체해서 앱이 이 파일에 의존하지 않습니다. `claude_missions` 컬렉션 문서도 그대로 남아 있지만 앱은 더 이상 읽지 않습니다.
